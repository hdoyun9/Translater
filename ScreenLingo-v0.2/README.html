SCREENLINGO · 0.2 BETA · WINDOWS x64

화면은 그대로,
언어는 한국어로.

실행 중에만 화면의 글자를 읽어 한국어 번역을 겹쳐 표시하는 개인용 시험 버전입니다. 별도의 Python 설치나 API 키가 필요하지 않습니다.

먼저 알아두세요
영어·일본어 가로/세로쓰기·중국어의 실제 Windows OCR과 로컬 번역, 원문 가림 표시를 테스트했습니다. 픽시브 만화는 원문 언어를 일본어, 글자 방향을 자동으로 선택한 뒤 읽을 영역을 지정하세요. 작은 글자·손글씨·효과음은 이미지 확대가 필요할 수 있습니다.

1. 실행하기

  1. ZIP 파일에서 모두 압축 풀기를 선택하세요. ZIP 안에서 직접 실행하지 마세요.
  2. 압축을 푼 폴더의 ScreenLingo.exe를 더블클릭하세요. runtime, app, models 폴더를 함께 유지해야 합니다.
  3. 첫 실행 안내에 동의하면 영어·일본어·중국어 자동 판별 번역이 시작됩니다. 다음 실행부터는 마지막 언어 설정으로 자동 시작합니다.
  4. 주 모니터에서 메모장 등에 Open the door and find the key.를 띄워 확인하세요. 앱 제어창 자체는 인식하지 않습니다.

영어·일본어·중국어를 한국어로 직접 번역하는 M2M100 INT8 모델을 포함했습니다. 이 모델이 있으면 언어별 추가 모델 다운로드는 필요하지 않습니다. Windows에는 인식할 언어의 OCR 기능과 최신 Visual C++ x64 재배포 패키지가 필요합니다.

2. 조작

기능동작
원문 언어영어 / 일본어 / 중국어 간체 / 자동(이 3개 언어)을 선택합니다. 자동 모드는 설치된 OCR 엔진을 순서대로 사용합니다.
만화 글자 방향자동 / 가로쓰기 / 세로쓰기를 선택합니다. 세로쓰기는 열 안에서 위→아래, 열 사이는 오른쪽→왼쪽으로 읽습니다. 작은 후리가나는 본문 발음으로 연결해 중복 번역을 줄입니다.
전체 번역 보기인식된 모든 영역의 번역을 스크롤하여 끝까지 읽습니다. 확인이 필요한 영역은 오류 사유를 표시합니다. 일시정지 후에도 마지막 결과를 읽을 수 있습니다.
영역 지정대사창 등 필요한 부분만 드래그합니다. 영역을 선택하는 동안에는 화면 캡처가 중단됩니다.
화면 전체주 모니터 전체로 돌아갑니다. 여러 모니터 동시 번역은 지원하지 않습니다.
일시정지화면 인식 프로세스를 끝냅니다. 재개하면 새 프로세스로 시작합니다.
번역 숨기기표시만 숨깁니다. 캡처·번역은 계속됩니다. 캡처 중단은 일시정지를 사용하세요.
X / 전체 종료앱과 하위 작업을 종료합니다. 트레이에 숨지 않습니다.
Ctrl + Alt + F8번역 시작 / 일시정지
Ctrl + Alt + F9번역 표시 / 숨기기
Ctrl + Alt + F10전체 종료

다른 프로그램이 단축키를 선점하면 단축키가 작동하지 않을 수 있습니다. 이 경우 제어창의 버튼을 사용하세요.

3. 개인정보와 실행 범위

  • 앱을 실행하지 않으면 이 앱에 의한 캡처·번역은 없습니다. 부팅 시 실행 등록, 예약 작업, Windows 서비스, 트레이 상주는 만들지 않습니다.
  • 화면 캡처·OCR·번역은 로컬에서 수행합니다. 스크린샷과 추출한 글자, 번역문을 파일로 저장하거나 서버로 보내지 않습니다. 번역 캐시는 실행 중 메모리에만 존재합니다.
  • 주 모니터 전체 모드에서는 알림·채팅 등 화면에 보이는 내용도 로컬 인식 대상입니다. 민감한 창이 있다면 영역을 제한하거나 일시정지하세요.
  • 인터넷은 사용자가 동의한 추가 모델 다운로드에만 사용합니다. 화면 캡처 프로세스를 종료한 상태에서 별도 다운로드 작업을 수행합니다. 모델 제공 서버에는 일반 다운로드처럼 IP 주소 등이 보일 수 있습니다.
  • 사용자 폴더 %LOCALAPPDATA%\ScreenLingo에는 언어·영역·글자 크기 등의 설정과 추가 언어 모델만 저장합니다. 중단된 모델 다운로드 임시 파일이 남을 수 있습니다.
  • 실행기가 Windows Job Object로 하위 프로세스 수명을 묶습니다. 앱이 종료되면 실행기도 종료되고 작업 프로세스를 정리합니다.
  • 운영체제의 메모리 페이징·시스템 진단이나 다른 프로그램의 녹화·전송까지 통제하는 보안 제품은 아닙니다.

4. 지원 환경과 한계

  • Windows 10 버전 2004 이상 또는 Windows 11, x64 PC. ARM 전용 환경은 테스트하지 않았습니다.
  • 최소 수 GB의 여유 메모리와 저장공간을 권장합니다. CPU 번역으로 GPU·CUDA가 없어도 실행하도록 구성했습니다.
  • OCR 줄을 위치와 글자 방향에 따라 문장 영역으로 묶고, 문장 경계를 유지해 번역합니다. M2M100이 있으면 영어 중간 번역 없이 한국어로 직접 번역합니다. 흐린 글자, 손글씨, 장식 폰트, 말장난·고유명사의 판독과 의미는 틀릴 수 있습니다.
  • 설정의 0.7~2초는 요청 간격입니다. 실제 결과는 OCR와 번역 시간만큼 더 늦습니다. 결과 처리 중에는 요청을 겹쳐 쌓지 않습니다. 같은 문장의 번역은 메모리 캐시를 재사용하지만 글자 인식은 갱신합니다.
  • 60줄·1,200자 잘림 제한을 제거했습니다. 고해상도 화면은 겹치는 타일로 읽고 원본/확대 인식을 합칩니다. 현재 주 모니터 또는 선택 영역에 보이는 글자만 대상이며, 스크롤 밖이나 아직 열지 않은 페이지는 읽지 않습니다. OCR 자체가 찾지 못한 글자까지 번역할 수 있는 것은 아닙니다.
  • 번역문은 클릭 통과 오버레이입니다. 원문 위치에 주변 색의 불투명 마스크를 그리고 한국어를 표시합니다. 공간이 부족한 항목은 번호로 안내하며 전체 번역 보기에서 전문을 읽을 수 있습니다. 장면이 바뀐 직후에는 갱신 간격만큼 이전 번역이 잠깐 남을 수 있습니다.
  • 독점 전체화면·DRM 보호·보안 화면·일부 안티치트 환경에서는 캡처나 오버레이가 지원되지 않습니다. 보호 기능을 우회하지 않습니다. 가능하면 일반 창 모드에서 시험해 주세요.
  • 서명되지 않은 개인용 베타 실행 파일입니다. Windows나 조직 정책이 실행을 막는 경우 보안 기능을 끄지 말고 중단하세요. 관리자 실행은 기본 요구 사항이 아닙니다.

5. 안 될 때

  • OCR 언어가 없음: Windows 설정 → 시간 및 언어 → 언어 및 지역 → 영어/일본어/중국어 언어 옵션에서 광학 문자 인식(OCR) 기능을 확인하세요. Windows 버전에 따라 메뉴 이름이 다를 수 있습니다. 앱을 다시 실행하세요.
  • DLL 또는 런타임 오류: 전체 폴더를 압축 해제했는지 확인하세요. 필요하면 Microsoft 공식 Visual C++ x64 재배포 패키지 안내를 확인하세요.
  • 화면은 읽지만 번역이 늦음: 영어 모드와 작은 영역으로 먼저 테스트하세요. 자동 모드와 화면 전체는 더 느릴 수 있습니다.
  • 설치되지 않은 자동 모드 언어: 상태창에 OCR 미설치 코드가 표시됩니다. 해당 언어는 자동 모드에서 누락됩니다.
  • 모델 다운로드 실패: 인터넷 상태·디스크 여유 공간을 확인하고 다시 시작하세요. 종료하면 다운로드도 중단됩니다.

6. 삭제와 소스

앱을 종료한 후 압축 해제한 폴더를 삭제하면 됩니다. 추가 모델과 설정까지 없애려면 사용자 폴더의 %LOCALAPPDATA%\ScreenLingo만 삭제하세요. 해당 폴더를 지우면 저장한 설정·추가 모델은 복구되지 않을 수 있습니다.

app에 Python 원본 소스, launcher.c에 실행기 소스, tests에 테스트를 포함했습니다. 제3자 구성 요소의 라이선스는 THIRD_PARTY_NOTICES.md와 각 패키지에 포함되어 있습니다.
