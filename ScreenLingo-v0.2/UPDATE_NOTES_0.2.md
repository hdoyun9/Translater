# ScreenLingo 0.2 번역·만화 표시 개선

적용일: 2026-09-13 / 범위 창·이름 처리 후속 업데이트: 2026-09-19

## 사용

앱을 완전히 종료하고 `ScreenLingo.exe`를 다시 실행합니다.
픽시브 일본어 만화는 **원문 언어: 일본어**, **만화 글자 방향: 자동 판별**로 시작하세요.
다른 언어가 섞여 있으면 원문 언어를 자동으로 선택합니다. 방향이 잘못 잡힌 컷에서는 세로쓰기를 직접 선택할 수 있습니다.
실행하면 초록색 사각형 번역 창이 표시됩니다. 상단 바를 끌어 이동하고 테두리·모서리를 끌어 크기를 조절하세요.
창 안쪽만 인식·번역하며, 가운데는 원래 웹페이지를 클릭·스크롤할 수 있습니다. 위치와 크기는 다음 실행에도 유지됩니다.

## 2026-09-19 후속 변경

- 전체화면·영역 지정 버튼을 제거하고 항상 보이는 이동·크기 조절 창으로 바꿨습니다.
- 조절 중에는 새 캡처를 요청하지 않고, 이전 범위에서 늦게 도착한 번역은 표시하지 않습니다. 번역문도 창 바깥으로 그리지 않습니다.
- 가타카나의 반각 문자·분리된 탁점과 OCR 장음 오인식(`コ - ヒ -` → `コーヒー`)을 보정합니다.
- 가타카나 이름·외래어를 별도로 번역한 표기로 유지해 같은 단어가 문장마다 달라지는 현상을 줄입니다. 설정에서 이 기능을 끌 수 있습니다.
- **이름·외래어 사전**에 `일본어 원문 → 원하는 한국어 표기`를 등록하면 자동 번역보다 우선합니다. 한자 이름과 다른 언어의 명칭도 등록할 수 있습니다.
- 전체 번역 보기에 OCR 원문도 함께 표시해 인식 오류와 번역 오류를 구분할 수 있습니다.
- 모든 캐릭터·브랜드의 공식 한국어 이름을 내장한 것은 아닙니다. 공식 표기가 중요한 이름은 사전에 등록하세요. OCR이 전혀 다른 글자로 읽은 단어는 원문 확인이 필요합니다.

## 변경

- 원문 위치를 불투명하게 가리고 한국어를 겹쳐 표시합니다. 주변 배경색을 사용하고 공간에 맞춰 글자 크기를 조절합니다.
- 모든 결과는 **전체 번역 보기**에서 스크롤해 읽을 수 있습니다. 화면에 충분한 공간이 없는 항목은 번호로 안내합니다.
- 60줄, 1,200자 잘림과 화면 아래 항목의 일괄 생략을 제거했습니다. 긴 입력은 남은 부분까지 나눠 처리합니다.
- 고해상도 화면을 축소하지 않고 겹치는 타일로 OCR합니다. 원본 크기와 확대 크기의 결과를 합쳐 인식 누락을 줄입니다.
- OCR 줄을 문장 영역으로 묶고 문장 경계에서 번역합니다. 세로 열은 위→아래, 오른쪽→왼쪽 순서로 읽습니다.
- 일본어/중국어 글자 사이의 불필요한 공백을 제거하고 자동 모드의 중복·오인 언어 결과를 줄였습니다.
- 작은 후리가나는 인접한 한자의 발음으로 연결합니다. 본문과 따로 엉뚱한 문장으로 번역하지 않으며 가림 영역에는 포함합니다.
- 영어를 중간 언어로 쓰던 번역보다 테스트 품질이 나은 **M2M100 418M INT8 직접 한국어 번역 모델**을 포함했습니다. 추가 용량은 약 496 MB입니다. CPU에서 실행하며 API 키와 번역 서버가 필요 없습니다.
- 실패한 문장을 버리거나 물음표를 정상 결과로 표시하지 않습니다. 해당 위치와 전체 결과에 확인 필요 표시·오류 사유가 남습니다.
- 처리 중인 결과를 점진적으로 표시하며, 같은 화면에서는 완료된 번역을 유지해 깜빡임을 줄입니다.
- 시스템 CJK 글꼴을 직접 등록하고, 긴 결과 및 작은 화면에서 컨트롤을 스크롤할 수 있게 했습니다.

| Please do not open the door until I return. | 반환까지 문을 열지 마십시오. | 내가 돌아올 때까지 문을 열지 마십시오. |

## 검증 범위

실제 Windows OCR과 실제 모델을 사용한 합성 이미지 테스트 및 Qt 렌더링 테스트입니다.
문제가 발생했던 실제 픽시브 작품 이미지는 제공되지 않아 그 컷의 `???` 현상 자체는 직접 대조하지 못했습니다.
손글씨·효과음·작거나 흐린 글자·특이한 말풍선 배치는 여전히 인식/문맥 오류가 날 수 있습니다.
현재 주 모니터의 초록색 번역 창 안쪽에 보이는 내용이 대상이며 스크롤 밖 페이지는 자동으로 읽지 않습니다.
인식된 글자를 코드에서 잘라 버리는 제한을 없앤 것이며 모든 원본 이미지의 100% 판독·번역을 보장하지는 않습니다.

모델 출처와 체크섬은 `THIRD_PARTY_NOTICES.md`, `DEPENDENCIES.json`, `models/m2m100/metadata.json`에 있습니다.
